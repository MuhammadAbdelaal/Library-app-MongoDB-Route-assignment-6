## (1): Create an explicit collection named “books” with a validation rule to ensure that each
document has a non-empty “title” field. 
----- (1) solution -----
 db.createCollection("books",{
    validator: {
        $jsonSchema: {
            bsonType: "object",
            required: ["title"],
            properties: {
                title: {
                        bsonType: "string",
                        minLength: 1,
                        description: "title is required field"
                    }
                }
            }
        }
});
